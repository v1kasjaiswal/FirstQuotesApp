# <div align="center">**🚀My First Quotes App🚀**
</div>

#### <div align="center">**Developed using Modern UI Toolkit - Jetpack Compose**
</div>

This is my first Jetpack Compose🚀 project. It is a simple Quotes application that displays random quotes and its respective authors. This application has different screens like the quotes list screen📃, loading screen and quote detail screen whereas, it displays quotes from a local file that is already embedded in res/raw/ folder📂. I chose Jetpack Compose over XML due its declarative UI nature⚡, concise code and performance efficiency👀. 

PS - I am not required to create adapters and all stuff to create a simple recycler view 😁.

### **// Features⚡**

- **Quotes List**: This screen displays a list of quotes with their respective authors.
- **Loading Screen**: This screen displays a loading text while fetching quotes.
- **Quote Detail**: This screen displays the details of a quote with its author.

---

### **// Compose UI Components 🪨**
- **Composable**: A function that is annotated with @Composable and describes a part of the UI.
- **Text**: Display text on the screen.
- **Column**: Arranges UI elements vertically.
- **Row**: Arranges UI elements horizontally.
- **Spacer**: Add space between UI elements.
- **LazyColumn**: Displays a list of items lazily.
- **Image**: Display images on the screen.
- **Card**: A container with rounded corners and elevation.
- **Surface**: A container with a background color and elevation.
- **Divider**: A horizontal line that separates content.
- **CoroutineScope**: A scope to launch coroutines.

---

### **// Libraries and Dependencies 🤖**
  
- **Jetpack Compose**: Modern declarative UI toolkit for building native UI.
- **Material UI 3**: Material Design components for Jetpack Compose.

### **// Installation 📲**

- Clone the repository using the following command:
  ```bash
  // Clone the repository
  git clone https://github.com/v1kasjaiswal/FirstQuotesApp.git

  // Change the directory
  cd FirstQuotesApp
  ```  
- Open the project in Android Studio and build the project.
- Run the project on an emulator or physical device.
